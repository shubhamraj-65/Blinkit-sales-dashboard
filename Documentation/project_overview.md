# 📊 Blinkit Sales Dashboard - Documentation

## 🧠 Problem Statement
To analyze Blinkit sales data and understand outlet performance, product trends, and customer behavior.

---

## 🎯 Objective
To build an interactive Power BI dashboard that provides actionable business insights from raw sales data.

---

## 📊 Data Used
- Sales transactions dataset
- Product category data
- Outlet information
- Ratings data

---

## ⚙️ Process Followed
1. Data cleaning using Power Query
2. Data modeling in Power BI
3. KPI creation using DAX
4. Dashboard visualization
5. Insights generation

---

## 📌 Key Features
- Sales Overview dashboard
- Product performance analysis
- Geographic sales distribution
- Deep dive analysis

---

## 🧮 Tools Used
- Power BI
- Power Query
- DAX
- Excel

---

## 📈 Outcome
The dashboard helps in identifying top-performing outlets, best-selling products, and regional sales patterns for better business decisions.
